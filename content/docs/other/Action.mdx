## 2026

10.04：站点框架由 VuePress 2 RC 迁移至 **Astro 7 + Fumadocs 16**。原 VuePress 2 已连续三年停留在预发布版本（rc.0 → rc.31），theme-hope 亦从 rc.2 跨越至 rc.109。迁移保留旧站 `.html` 网址格式，并为分区目录生成跳转页以避免外部链接失效。

10.04：补充站点地图、`robots.txt` 与 `llms.txt`；清理已随 PWA 移除而失效的图标资源。

10.04：补齐 9 个长期空白的条目——漫画衍生作品、角色登场人物、动画第三季与剧场版、官方衍生书籍、相关软件与游戏。

10.05：修复两处自迁移以来一直存在的缺陷。其一，评论区因挂载方式与 Waline 3 的实际接口不匹配而从未生效；其二，搜索索引中混入了组件源码，搜索结果摘要直接显示标签原文。

10.05：架构图组件补上失败兜底。此前的实现只要 `mermaid.render()` 被拒绝或迟迟不返回，页面上就会留下一个没有任何提示的空盒子；现在改为超时即显示图表源码与错误信息，并在深浅色切换时重绘以同步配色。

10.05：补齐「官方商品&特典」与「IP 授权周边产品」两页；下线信息难以客观枚举的「粉丝圈」与「同人作品」两个分类。

10.05：为全部页面补齐 canonical 规范地址；移除引用已不存在图片的遗留图库页。

10.05：引入 `pnpm check` 站点审计脚本并接入部署流水线，覆盖页树漂移、SEO 元信息、站点地图覆盖度、站内死链、组件残留与静态资源缺失六类检查；同时修复一处 high 级依赖漏洞。

10.05：修复部署流水线。流水线自框架迁移以来从未成功执行过，站点内容一直未能上线；现已通过流水线自检，域名发布待 GitHub Pages 启用后生效。

10.05：**「原声带OST」「片尾曲ED」「动画第一季」三页的标签页改为分节展示。** 标签页自迁移以来就一直是坏的——标签栏能正常显示，但面板数恒为 1，点击任何标签看到的都是同一块全部内容。原因是 Astro 的 MDX 运行时会把标签页内的所有内容作为单个节点交给组件，组件无法按标签边界拆分。现改为页首锚点导航 + 小节标题，内容本身未作改动。

10.05：流水线加固。新增审计规则自身的元测试与搜索索引回归测试并接入流水线；升级全部 action 至 Node 24 世代，锁定 runner 版本以避开 2026-10-19 的 Ubuntu 26 迁移。

10.05：**补齐全站社交分享卡片。** 原有的一行 `og:image` 写在了页面组件的插槽里，被渲染到了 `<body>` 起始处，而 Twitter、Facebook、Slack 等平台只解析 `<head>`，等于完全没写。现将 Open Graph 与 Twitter Card 元信息统一移入 `<head>`，补齐标题、描述、规范地址与预览图，预览图改用绝对地址。首页与 404 页同步处理，404 另加 `noindex`，避免薄内容页被索引。

10.05：**修正「漫画」三个条目的标题层级。** 正文用 `#` 写小节，导致每页出现 4～7 个一级标题，读屏用户会听到多个「标题一级」，这些小节也进不了页面目录。现统一降为 `##`（参考资料降为 `###`），文字内容未作改动。

10.05：审计新增五类检查——一级标题唯一性、社交分享卡片完整性、Twitter Card、跨页重复标题、404 的 noindex，并全部配了正反用例（元测试由 18 项增至 28 项，仍是 0 盲区 0 误报）。旧链接跳转页同步补上 viewport，并沿用目标页标题，避免全站标题重复。

10.05：**全站三成页面共用同一条描述。** 内容页的 frontmatter 基本只写了标题，描述缺省时全部落到同一个兜底值，等于三十个页面共用一句模板话，搜索结果里的摘要位白白浪费。现改为「frontmatter 优先，缺省则从正文首段自动派生」：跳过标题、表格、列表、代码块、组件与锚点导航，剥掉内联 Markdown 标记，截到 160 字以内。其中 8 页（两个卡片索引页、主题曲/片尾曲/原声带/手游曲、更新日志、漫画衍生作）自动挑不出合适的句子，改为手写。审计新增「描述仍为兜底值」与「跨页描述重复」两条检查，并为此单列了一组单元测试。
