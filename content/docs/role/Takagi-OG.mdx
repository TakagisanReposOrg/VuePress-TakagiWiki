《擅长捉弄的高木同学》正篇主要角色一览。CV 以 TV 动画（2018 年～2022 年，共三季，制作：シンエイ動画）为准；剧场版（2022 年）沿用同一套配音阵容。

## 主要角色

| 角色 | CV | 简介 |
| --- | --- | --- |
| 高木さん | 高橋李依 | 女主角，西片的邻座同桌。以捉弄西片为乐的"捉弄高手"，几乎总能看穿西片的心思并先发制人。喜欢西片，但从不直接说破，而是把心意藏进一次次捉弄里。 |
| 西片 | 梶裕貴 | 男主角。性格认真又容易害羞，每次被高木捉弄都会涨红了脸不服输，却总落入圈套。嘴上绝不承认，其实非常在意高木。 |
| 美奈（日々野ミナ） | 小原好美 | 高木的好友，"三人娘"之一。开朗的大胃王，观察力意外地敏锐，经常第一个看穿高木与西片的关系并大声起哄。 |
| 友加里（天川ユカリ） | M・A・O | 高木的好友，"三人娘"之一。认真稳重，对恋爱话题兴趣浓厚，常和美奈一起调侃西片与高木。在番外《明天是星期六》《与恋爱相恋的友加里》中担任主角。 |
| 早苗（月本サナエ） | 小倉唯 | "三人娘"之一，隶属陆上部。冷静的吐槽役，常被精力过剩的美奈折腾，偶尔一针见血地点破现场气氛。 |
| 真野 | 小岩井ことり | 西片与高木的同班同学（班委），认真细心。与中井之间有一段朦胧的暧昧关系。 |
| 中井 | 内田雄馬 | 西片的同班同学，单恋真野，时常就"怎么拉近关系"向高木和西片请教（并反过来被捉弄）。 |
| 高尾 | 岡本信彦 | 西片的男生朋友，经常和西片一起行动，也是"恋爱商谈"的常客。 |
| 木村 | 落合福嗣 | 西片的同班同学，体格健壮、性格憨厚的男生的代表，常围观西片与高木的攻防。 |
| 北条 | 悠木碧 | 班上的女生，与濱口是一对，是班里另一段众所周知的恋情。 |
| 濱口 | 内山昂輝 | 西片与高木的同班同学，北条的男友。 |

## 关于"千"

正篇 TV 动画的同学中并没有名为"千"的角色。与"千"相关的人物是高木与西片未来的女儿——西片ちー（小千）：她在剧场版《擅长捉弄的高木同学》（2022）中登场，CV 为宮本侑芽，并作为续篇漫画《擅长捉弄的（原）高木同学》的主角活跃，详见本站"高木番外角色"页。
